SiFa Manager – Ausbauversion

Dateien im GitHub-Repository im Hauptverzeichnis ablegen: index.html, manifest.json, sw.js, icon-192.png, icon-512.png.

Wichtig: Vor dem Ersetzen der bisherigen App in der alten App eine JSON-Datensicherung exportieren. Die neue Version behält kompatible alte Datensätze (gb, mass, stoff, mittel, pruef, unter) bei, sofern dieselben Browserdaten genutzt werden. Bei Upload über GitHub Pages werden Browserdaten nicht automatisch gelöscht.

Speicherung lokal im Browser; keine Synchronisierung/Mehrbenutzerverwaltung. Für vertrauliche Echtdaten ist eine geprüfte, abgesicherte betriebliche Lösung erforderlich.
